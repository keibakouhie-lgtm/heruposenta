# トレぴ ヘルプセンター

トレぴ（トレーディングカードショップ）のスタッフ用マニュアルサイトです。
`index.html` を開くだけで動きます（画像も記事も1ファイルに入っています）。

## フォルダの中身

| 場所 | 中身 |
| --- | --- |
| `index.html` | 完成したサイト。**直接編集しない**（下の手順で作り直す） |
| `manuals/` | 元のWordマニュアルと、記事との対応表 `manuals.json` |
| `data/articles.json` | 全記事のデータ（タイトル・本文・カテゴリ・よく見られるガイドの設定など） |
| `assets/` | ロゴと記事内の写真 |
| `src/template.html` | サイトのデザインと動き（カテゴリ一覧・検索・計算ツール） |
| `tools/` | Wordの取り込みとサイトの組み立て用スクリプト |

## マニュアルを更新するとき

必要なもの：Python 3、`pip install pillow`、[pandoc](https://pandoc.org/)

1. `manuals/` の該当するWordファイルを新しい版に差し替える
2. 変わる記事を確認する
   ```
   python3 tools/import_docx.py oripa --dry-run
   ```
3. 取り込んで、サイトを作り直す
   ```
   python3 tools/import_docx.py oripa
   python3 tools/build.py
   ```
4. ブラウザで `index.html` を開いて確認し、コミットする

`oripa` の部分は `manuals/manuals.json` のキーです：
`kaitori`（買取査定）／`recore`（現場実務）／`taikai`（大会運営）／`bouhan`（防犯）／`unei`（店舗運営）／`open`（オープン準備）／`close`（閉店）／`oripa`（オリパ）

### 注意

- 取り込むと、そのマニュアルの記事は**Wordの内容で丸ごと置き換わります**。
  サイト上で書き足した説明は消えるので、残したい内容はWord側に入れてください。
  - いま `kaitori`（買取査定）と `oripa`（オリパ）の記事には、サイト上で足した説明があります
    （写真の説明文、POSレジ記事への案内）。取り込む前に `--dry-run` で確認してください。
- **POSレジ操作（RECORE）**の11記事（`pos-` で始まる記事）は、元のWordファイルがありません。
  `data/articles.json` を直接編集して更新します。
- 新しいマニュアルを追加するときは、`manuals.json` に項目を足し、
  新しいカテゴリが必要なら `src/template.html` の `CATS` にも追加します。

## マニュアル同士の食い違い（本部確認中）

次の5点は、マニュアルによってルールが違うため、該当記事に注意書きを出しています
（`data/articles.json` の `notes`）。正しいルールが決まったら注意書きを外してください。

1. 状態ランクの名前と減額率
2. 18歳未満の買取（保護者同伴の要否）
3. 真贋確認に使う機材
4. 不正が疑われる商品を目の前で扱うか、バックヤードへ下げるか
5. 金庫で保管する商品の金額ライン
